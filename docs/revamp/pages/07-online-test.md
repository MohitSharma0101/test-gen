# Online Test (`/online-test`)

**Contract:** pick a batch → its scheduled papers; Live marker; per test:
view paper, view results, question analyzer, delete (confirm). Shows
duration, start, end.

**Target:** PageHeader (Timer, Daily tone, Refresh). Batch picker remembered
on this device. One list sorted live → upcoming → ended (no section headings — they felt
overwhelming), each card with a status badge and one time line ("20 Nov, 10:30 AM – 11:30 AM · 180 min"). Results
and Analyze are visible buttons; View paper and Delete in the ⋯ menu.
Cards: 1 column on phones, 2 on desktop. States: pick a batch (empty),
loading skeleton, error + retry, none scheduled (points to Papers, where
tests are scheduled).

**Out of scope:** the results / analyzer sheets themselves.
