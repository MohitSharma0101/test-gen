# Generate Paper (`/generate-paper`)

**Contract:** per-subject plans (chapters, count, marks, tag quotas, unused
only), availability counts and warnings, generate / reshuffle, swap or
remove a question, show answers, 2 columns, start over, save / preview /
print (usage counted).

**Target (same semantics as Create Paper):** setup panel on the left (one
scroll, Generate pinned at its foot; class, subject chips, count presets,
marks + Unused, tag quotas, chapters). Paper on the right: one toolbar row
(count, Reshuffle, Answers, 2 columns, Start over), compact cards with
answers folded, subject blocks. Bottom paper bar: totals, 1M×n breakdown,
Save, Preview (v2), Print. Phone: setup → paper as two steps; paper bar is
Save / Preview / Print. Plans + paper auto-restored after refresh
("Unsaved paper restored · Start new"), cleared after Save.

Setup panel v2: class + subject chips in one row; count/marks/unused/tags folded
into one summary row ("Maths: 20 questions · any marks"); the chapter tree
fills the rest and scrolls on its own (~300px at 1366x650, was ~0).
